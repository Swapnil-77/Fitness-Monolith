# Fitness Monolith

Fitness tracking application built with Spring Boot, Java 21, MySQL, HTML, CSS, and JavaScript.

## Project Structure
- fitness-backend: Spring Boot backend and REST APIs.
- fitness-frontend: HTML, CSS, and JavaScript frontend.

## Run Backend
Open PowerShell inside fitness-backend and run: .\mvnw.cmd spring-boot:run

## Run Frontend
Open fitness-frontend/index.html in your browser.
